Readme
======

mir-platform-android - android driver for the mir cross-platform display manager
------------------------------------

Mir is a display manager that provides efficient support for graphics coprocessors.

Build instructions
------------------

The reproducible ARM64 container build, Debian packaging command, artifact
checks, and troubleshooting notes are documented in
[`docs/mir-build-container.md`](docs/mir-build-container.md).
